# Catppuccin Macchiato

A bIRC colorscheme adapted from [Catppuccin Macchiato](https://github.com/catppuccin/nvim).

![Approximate bIRC preview of Catppuccin Macchiato](preview.svg)

The preview is illustrative: actual typography, spacing, and interface
chrome are controlled by bIRC. The three colors match the JSON exactly.

## Mapping

- Appearance: `dark`
- Background: `#24273a`
- Text: `#cad3f5`
- Accent: `#c6a0f6`
- Palette basis: Catppuccin Macchiato base, text, and mauve.

The original editor theme has many syntax and interface colors. bIRC's
export format has one background, one text color, and one accent, so this
adaptation preserves the upstream Normal/editor canvas and chooses a
representative upstream highlight color for the accent.

## Upstream

- Canonical Vim/Neovim source: [https://github.com/catppuccin/nvim](https://github.com/catppuccin/nvim)
- Upstream license: `MIT`

The upstream project remains the authority for its name, palette, license,
variants, and current maintenance status. This directory contains only a
small interoperable palette adaptation, not upstream Vim or Neovim code.
